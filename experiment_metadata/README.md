# 実験条件の参照データ

`run_order_20261103.json` は、録画番号・グループ・試行条件を解析結果へ結び付けるためのスナップショットです。録画側の試行順生成コードには依存せず、解析用の参照値としてのみ使います。更新が必要な場合は、録画側で確定した新しい `run_order.json` を別名でコピーし、スナップショット日付を記録してください。

グループ６・７・９には、録画先や実際の条件について実験者から申告された例外があります。[例外の概要](recording_exceptions_20261106.md)と[機械可読の記録](recording_exceptions_20261106.json)を確認し、未確認の対応を試行計画や録画番号から補完しないでください。元の試行計画と録画進捗ファイルは変更していません。
