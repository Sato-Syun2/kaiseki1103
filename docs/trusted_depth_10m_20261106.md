# 深度位置の10 m制限と急変の保留

2026-11-06の指示により、通常利用する位置はカメラ床面投影を原点とする**廊下方向Xが10 m以下**かつ推定された両壁の内側に限定する。X=10 mと壁上は含む。位置が無い観測は範囲を判定できないため欠測のまま保持する。直線距離10 mや身体中心までの距離とは異なる。10 m以内の正確さを実測で保証したものではない。

元の深度座標や既存の15 m版を変更せず、共有先 `exchange/depth_group002_005_trusted10_20261106_01/originals/` に新しい座標と照合記録を作成する。録画・深度画像は共有しない。以前の仮ID再割当て候補は10 m版に自動適用していない。元の追跡IDは10 mを超える観測も含む解析時に割り当てられており、10 m以内だけでIDを再推定したものではない。

## 急変の扱い

範囲内の同一IDについて、隣接フレーム間0.15秒以内に水平面で0.6 m以上かつ4 m/秒以上動いた場合を急変候補とする。位置は身体中心ではなく衣服などの可視表面であり、速さは身体の実速度ではない。

- 周囲の位置に短時間で戻り、前後に整合する位置がある場合は、１〜４フレームの孤立した飛びを欠測にする。
- それ以外の急変はどちらが誤っているか確定できないため、急変の前後２点を両方欠測にし、速度や軌跡の線をつながない。
- 座標やIDを新しく推定・補間せず、元座標は原本と報告書に保持する。ID未確定の点には同一人物としての速度検査はできない。判定には誤除外の可能性がある。

位置を保留したことと、実際の速度や位置の精度が上がったことは別。欠測をまたぐ不連続、複数人のID入れ替わり、誤った検出・深度誤差は残りうる。
