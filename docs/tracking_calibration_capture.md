校正と撮影比較の準備（2026-11-04）

中央の3・5・7m…へポールを移動させる計画は、距離帯ごとの差を調べるために使えます。3D姿勢を求める校正では、中央一直線だけにせず左右と高さの異なる点も含めます。細い無地のポールの縁だけでは背景深度を拾いやすいため、既知の位置に模様のあるつや消し標的面を固定してください。

1. 現場で記録する値

- カメラの設置ID、固定位置、高さ・角度、serial、解像度、fps、露出、照明、深度モード、日時。解像度や再設置の変更は別条件とする。
- 原点はカメラ光学中心の床面投影。Xは廊下軸方向、Yは横方向、Zは床から上向き。3m等は廊下方向の距離で、斜距離や標的表面までの距離と混同しない。
- X=3・5・7・9・11・13・15mなど、実際に追跡する距離帯。左右の歩行位置と、床付近・高さ1m・1.5m等の点を含める。
- 各位置で数秒静止し、複数回記録する。標的中心のX/Y/Z、標的厚さ、測量方法と精度を記録する。
- 検証用は4・6・8m等の別位置と別capture_idを使い、変換の推定に入れない。検出できなかった予定標的も記録する。

2. 入力ファイル

`configs/calibration_points_template.csv` をコピーして測量値を入力します。`split` は `calibration` または `validation`、`status` は `valid` または `missing` です。

`camera_x_m/camera_y_m/camera_z_m` は、測量した標的点と画像上で同定した同じ点のSDK IMAGE座標です。SDKの整流済み左画像・同じフレームの深度から取得してください。人物の骨盤、頭、推定床から値を作ってはいけません。rawの深度を書き出す既存ツールは共有SDKフォルダーの `export_zed_depth.py` で、使用時は `--depth-mode NEURAL` と標的を拾える画素間隔を指定します。保存したXYZと内部パラメータで対応画素を確認し、細い標的の周辺・背景の点を平均しないでください。この校正CLIは測量済み対応点を入力として受け取り、ポールを自動認識するものではありません。

`target_X_m/target_Y_m/target_Z_m` は独立した測量値です。SDK深度が取れなかった行はstatus=missingとし、camera座標を空欄にして、予定した標的・測量値・capture_idは残します。source_svo、frame_index、u、v等の追跡用列を追加しても構いません。対応点の根拠を原画像へ戻せるようにしてください。

camera.jsonには実際の `setup_id`、`serial_number`、`width`、`height`、`intrinsics_left`、`depth_mode`、`coordinate_system`、`coordinate_units` を保持します。v2 SDKはこれらを記録します。旧camera.jsonへ新設置のIDを付けて新校正を使い回してはいけません。

```bash
python3 calibrate_corridor.py /path/to/surveyed_points.csv \
  --camera /path/to/matching_camera.json --setup-id hallway_calibration_202611XX \
  --baseline results/recording_001/zed_depth_review/zed_corridor_candidate.json \
  --output results/tracking_v2/calibration_NEW
```

有効な校正点を最低6点必要とし、一直線の配置・同じ検証位置の流用・capture_idの重複を拒否します。剛体変換をRANSACで推定し、独立検証点の符号付き偏り、MAE、RMSE、95パーセンタイルを距離帯・左右位置・高さ別に出します。missing行を含む予定点リストから欠測率も出します。入力に記載しなかった失敗は欠測率に含められません。

結果は `calibration.json` と `residuals.csv`。実データによる独立検証を確認するまでprovisional扱いです。変換だけで残る距離依存の誤差はGoal Bで調べ、根拠なく高次補正を追加しません。取得できなかった遠方・高さは未検証のまま報告します。今回の既存48録画には新しい測量値がないため、絶対位置誤差は未評価です。

3. 720pと1080p、配置の比較

まず同じ固定位置、30fps、歩行条件、照明・露出条件で720pと1080pを複数回撮影します。次に同一解像度で、廊下中心からの側方位置・設置高さを比較します。解像度と設置変更を一度に変えず、条件・実施順序・繰り返し番号を残してください。ZED 2iは解像度で画角が変わるため、足元や左右端の欠けも確認します。[公式画角資料](https://support.stereolabs.com/articles/8809264540-what-is-the-camera-focal-length-and-field-of-view)

単独歩行、縦並びの開始、左右それぞれの追い越し、交差、短い遮蔽を含めます。二人の間隔を段階的に変え、開始位置と動き出しの時刻を記録してください。可能なら身体を覆わない識別しやすい印を使い、実験参加者の番号との対応を別に記録します。実験中に推定結果を見て設定を変えた試行は、固定設定の評価試行と分けます。

評価は共通時刻で、ID取り違え・誤統合・分断、画像で確認した人物の取得時間・最大欠測、追い越し前の取得時間、視野欠け、動体ぶれ、処理時間、容量を比較します。30fps保存で点数が増えただけでは改善と数えません。頭部出力・部分観測・再対応付けは一つずつ有効化して効果を分けます。

後方人物が完全に隠れる区間を観測する必要がある場合は、別方向のカメラ等が必要です。その場合は設置間の姿勢、時刻、人物対応を別途校正します。現在の単眼方向の画像に存在しない人物軌跡を、補間や一定速度延長で測定扱いしないでください。
