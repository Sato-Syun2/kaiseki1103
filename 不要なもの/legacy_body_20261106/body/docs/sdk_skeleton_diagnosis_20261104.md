# 骨格不安定の切り分け（2026-11-04）

## 現在の観察

- グループ3録画002の1.003〜1.907秒、保存画像10枚に対する既存の人物可視領域注釈では、現行SDK出力の少なくとも1骨格の骨盤・胸・頭の関節が2人の領域にまたがる例が10枚すべてにあった。可視領域自体が重なるため、画素だけでは関節所属を断定できない。これは画像上での人物の重なりとSDK骨格の対応が難しい例であり、全録画の誤検出率ではない。`results/tracking_v2/stability_compare_group003_002_overlap_20261104_02.json`
- グループ2録画001ではSDK ID 0の7.894、7.927、7.961秒に、SDK出力の骨盤位置と2D位置が大きく往復した。SDK外の廊下座標変換やLiDAR対応付けより前に発生している。SDK内部で検出・人物ID・深度・追跡・フィッティングのどれが主因かは未確定。`docs/skeleton_motion_investigation_20261104.md`
- 床・壁から作る固定された暫定の廊下座標変換は絶対位置のずれには影響するが、元SDKデータにある1フレームの変化を発生させるものではない。LiDAR点群への人体対応付けは現在の再生処理では使っていない。

## SDKの2D・3D出力の対応確認

現行出力の保存画像フレームに限り、tracking_state OK、対象関節の信頼度20以上、2D位置が画像内、3D z > 0.25mで有限、骨盤(0)・左膝(19)・頭(26)の各関節について、camera.jsonの左カメラの補正済み内部パラメータで3D点を画像へ投影し、同じSDK関節の2D座標との差を計算した。画像時刻におけるサンプリングであり、可視性の正解判定は行っていない。

|---|---:|---:|
| group002 recording_001 | 546 | 0.000105 px |

対象範囲では、カメラ情報、軸の意味、2D・3D表示に大きな取り違えは見つからず、出力されたSDK関節の2D座標と3D座標は投影上ほぼ同じ位置を示している。ただし同じ関節出力間の整合性であり、2D点と3D点が独立した正解や実測であることは示さない。正しい人物に対応しているか、深度が正しいかも確認できない。特に3Dを2D画像に投影すると奥行き誤差を見落とす場合がある。

## 比較済みのSDK設定

現行のACCURATE GEN_2、MEDIUM GEN_2、予測0秒、検出信頼度50を同じ3 SVOで比較。信頼度50は2録画で骨盤の大きな飛びの診断数が減ったが、別の1録画では減らなかった。MEDIUMは人物重なり時の混合を避けた10画像で後方人物領域に関節が入らなかった。予測0秒では飛びが増えた録画がある。既定設定を変更して改善したとは言えない。`results/tracking_v2/stability_comparison_20261104_result.md`

SDKログはBODY_34でフィッティングを自動有効化すると報告した。無効指定パスは実際には無効化できていない。公式のAPI資料でもBODY_34はフィッティングが必要とされる。BODY_18でフィッティングを変える比較は可能性だが、形式自体も変わり、骨盤番号・関節名や既存のBODY_34専用リーダーへの影響を別途処理しなければならない。実録画での結果はまだない。

## 原因を切り分ける次の作業

1. 同じ映像の単独歩行・2人の非重なり・重なり・画面端・遠方の代表時刻を画像で注釈する。2D骨格の人物対応、3Dの飛び、欠測を別々に確認する。単独歩行にも発生するかどうかで、人物間混在が必要な条件かを調べる。
2. 問題の時刻と前後の全フレームで、同じ左画像、SDK骨格、対応するZED深度・信頼度画像を保存し、人物と背景の深度が分かれているか確認する。現在のスパイク例の個別原因は、深度画像未照合なので断定しない。既存のLiDARではなくZEDの深度をまず確認する。
3. BODY_18を別出力として試す場合は、関節の定義と有効点を形式別に扱い、BODY_34で得られた不自然な点・誤混在・欠測について同じ画像・同じ時刻で比較する。フィッティングの有無と骨格形式の変更が同時に起きるため、比較だけで原因を一つに特定しない。
4. 解析側は、単発の大きな飛びを判定候補として保留し、原SDK点と保留理由を保存する。連続した誤追跡や混合骨格はこの条件だけで除去できない。独立の画像注釈で誤除外と見逃しを評価してから使う。
5. 次回撮影ではグループ2の後方人物を見やすい配置を保持した上で、同じ位置・姿勢で単独・2人歩行を繰り返し、720pと1080pを順番に比較する。距離、照明、人物間隔、視野の欠けを記録する。カメラ移設・設定変更時は廊下座標の校正適用条件も確認する。
